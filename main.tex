\begin{abstract}
We formalize an end-to-end system designed primarily as a \emph{VRAM-reduction layer} for large language models:
by strictly bounding and intelligently selecting context via deterministic integer-only retrieval,
it enables running large models at very low VRAM, on commodity and older hardware.
We call the retrieval component \emph{Hohlfeld Resonance Model} (HRM), grounded in the
\emph{Hohlfeld Data Representation} (HDR) method.
The full pipeline consists of:
(1) HDR-derived integer signatures and resonance retrieval (HRM);
(2) integer Maximal Marginal Relevance (MMR) selection;
(3) deterministic prompt budgeting; and
(4) a local renderer (with optional custom FlashAttention kernel).
Full determinism of the retrieval core is a strong additional property with formal proofs
(end-to-end determinism, candidate completeness, MMR correctness).
Resonant Sparse Attention, a MatMul-free transformer-style extension, is also proposed.
\end{abstract}

\section{Motivation and Positioning}

Large language model inference imposes two primary VRAM demands:
(i) static model weights, and (ii) the key-value cache that grows with context length.
Standard retrieval-augmented generation (RAG) systems typically address (ii) at most,
and introduce non-determinism through probabilistic vector similarity search.

\textbf{HRM FlashRenderer} addresses \emph{both} VRAM demands by a different mechanism:
the retrieval core (HRM) strictly bounds the context delivered to the renderer
using deterministic integer arithmetic, so the renderer itself can be a small,
CPU-mapped model requiring zero VRAM by default.

by strictly bounding and intelligently selecting context.
Full retrieval determinism is a strong additional property of the system, not its sole purpose.

\section{Scope and Non-Negotiable Design Goals}
This work targets reproducible, machine-checkable behavior.
The design goals are:

\begin{itemize}
  \item \textbf{VRAM efficiency:} large models run locally with minimal GPU memory via strict context bounding.
  \item \textbf{Superdeterminism (retrieval core):} identical inputs yield identical retrieval outputs across runs and platforms.
  \item \textbf{Integer-only retrieval:} bounded integers; no floating point; no stochastic sampling in the core.
  \item \textbf{MatMul elimination (retrieval core):} the HRM retrieval avoids dense matrix multiplication entirely.
\end{itemize}

\begin{remark}
This paper does \emph{not} claim that eliminating MatMul automatically yields human-level language understanding.
It claims that a transformer-style \emph{control structure} (multi-head, multi-layer, context-dependent selection) can be implemented
via deterministic sparse associative operators derived from HDR, rather than via dot products and dense linear layers.
\end{remark}

\section{HDR: Deterministic Residual-Vector Encoding}
HDR defines a deterministic and proportional framework for encoding an ordered dataset
$D=\{d_1,d_2,\dots,d_n\}$ as a linked set of residual vectors relative to a reference vector $v_0$.
Each data point $d_i$ is represented by a residual vector $v_i$ with length (amplitude) $L_i$ and angle (phase) $\theta_i$:
\begin{equation}\label{eq:hdr_vec}
v_i \;=\; L_i\bigl(\cos(\theta_i)\hat{\imath} + \sin(\theta_i)\hat{\jmath}\bigr),
\end{equation}
with angles distributed deterministically by
\begin{equation}\label{eq:hdr_theta}
\theta_i \;=\; \frac{2\pi i}{n}.
\end{equation}
HDR further states that the original data can be reconstructed exactly via the cumulative sum of residual vectors:
\begin{equation}\label{eq:hdr_recon}
d_i \;=\; v_0 + \sum_{k=1}^{i} v_k.
\end{equation}

\begin{assumption}[HDR axioms]\label{ass:hdr}
Equations \eqref{eq:hdr_vec}, \eqref{eq:hdr_theta}, and \eqref{eq:hdr_recon} are applied as specified in the HDR method,
with a fixed reference vector $v_0$ (typically the zero vector) and a fixed ordering of data points.
\end{assumption}

\begin{proposition}[Exact reconstruction]\label{prop:hdr_exact}
Under Assumption~\ref{ass:hdr}, the dataset $D$ is reconstructible exactly from $(v_0,v_1,\dots,v_n)$ by \eqref{eq:hdr_recon}.
\end{proposition}
\begin{proof}
Equation~\eqref{eq:hdr_recon} provides the reconstruction rule. Because it is a deterministic cumulative sum over the residual vectors,
the reconstructed $d_i$ is uniquely determined for each $i$.
\end{proof}

\begin{proposition}[Uniqueness (HDR-level)]\label{prop:hdr_unique}
Under Assumption~\ref{ass:hdr}, uniqueness follows from (i) distinct angular mapping via \eqref{eq:hdr_theta}
and (ii) proportional length encoding via $L_i$; therefore different ordered datasets induce distinct HDR representations.
\end{proposition}
\begin{proof}
Distinct positions $i$ yield distinct angles by \eqref{eq:hdr_theta}. Given fixed ordering, each residual vector is determined by
its pair $(L_i,\theta_i)$; changing either magnitude or position changes at least one residual vector, and therefore changes the representation.
\end{proof}

\section{From HDR to Discrete Resonance Keys}
To eliminate MatMul in retrieval and sequence selection, we map streaming inputs to \emph{discrete resonance keys}
that are sparse by construction.

\begin{definition}[Discrete key space]
Fix $B=2^b$ bins. The discrete phase circle is $\mathbb{Z}_B = \{0,1,\dots,B-1\}$.
\end{definition}

\begin{definition}[Deterministic key extractor]\label{def:key_extractor}
A deterministic key extractor is a function
\[
P:\Sigma^\ast \to (\mathbb{Z}_B)^\ast
\]
that maps an input sequence to an ordered list of bin indices.
\end{definition}

\begin{assumption}[Fixed integer kernel]\label{ass:kernel}
$P$ is implemented solely via fixed, bounded integer arithmetic (e.g.\ fixed-window integer convolution and a deterministic
bin-mapping rule), and its parameters are fixed for a given system version.
\end{assumption}

\begin{proposition}[Key determinism]\label{prop:key_det}
Under Assumption~\ref{ass:kernel}, $P(x)$ is deterministic for any $x\in\Sigma^\ast$.
\end{proposition}
\begin{proof}
$P$ is a composition of deterministic integer operations with fixed parameters.
\end{proof}

\begin{remark}[Representation vs.\ projection]
HDR as stated in Section~2 provides exact reconstruction at the residual-vector level.
A discrete key extractor $P$ is a \emph{projection} used for routing/association; it may be lossy by design.
This work uses HDR to justify deterministic, proportional, ordered encoding; it uses $P$ to obtain sparse, hardware-friendly keys.
\end{remark}

\section{HRM: Resonance Retrieval by Inverted Index}
Let the corpus be $D=\{d_1,\dots,d_N\}\subseteq\Sigma^\ast$. We use the discrete keys produced by $P$.

\begin{definition}[Signature set]
For an item $x$, define a set signature
\[
S(x)\defeq \{\,k\in\mathbb{Z}_B : k \text{ occurs in } P(x)\,\}.
\]
\end{definition}

\begin{definition}[Posting index]
Define $B:\mathbb{Z}_B\to\mathcal{P}(\{1,\dots,N\})$ by
\[
B(k)\defeq \{\, i : k\in S(d_i)\,\}.
\]
\end{definition}

\begin{definition}[Resonance score]
For query $q$ and item $d_i$, define
\[
R(q,i)\defeq \abs{S(q)\cap S(d_i)}.
\]
\end{definition}

\begin{definition}[Candidate set]
\[
C(q)\defeq \bigcup_{k\in S(q)} B(k).
\]
\end{definition}

\begin{lemma}[Candidate completeness]\label{lem:candidate}
If $R(q,i)>0$, then $i\in C(q)$.
\end{lemma}
\begin{proof}
$R(q,i)>0$ implies $S(q)\cap S(d_i)\neq\varnothing$, so there exists $k\in S(q)$ with $k\in S(d_i)$.
Then $i\in B(k)$, hence $i\in C(q)$.
\end{proof}

\begin{definition}[Deterministic Top-$K$]
Fix a total order $\prec$ on ids (e.g.\ numeric ascending). Define $\mathrm{TopK}(q)$ as the ordered list of the $K$ ids with
largest $R(q,i)$ over $i\in C(q)$, breaking ties by $\prec$.
\end{definition}

\begin{theorem}[Deterministic retrieval]\label{thm:retrieval_det}
Under Assumptions~\ref{ass:kernel} and fixed tie-breaking order $\prec$, $\mathrm{TopK}(q)$ is deterministic.
\end{theorem}
\begin{proof}
By Proposition~\ref{prop:key_det}, signatures are fixed; therefore all $R(q,i)$ are fixed.
A deterministic tie-break over a total order yields a unique ranking.
\end{proof}

\section{Resonant Sparse Attention: MatMul-Free Transformer-Style Sequence Modeling}
We now describe a deterministic alternative to dot-product self-attention and dense linear layers.

\subsection{State construction (multi-head, multi-lag, multi-layer)}
Let a streaming input be tokenized into bytes $\{0,\dots,255\}$.
A fixed HDR-derived kernel produces, at each step, one bin per head.
We store the last $L$ bins (lags) for each head and each layer.

\begin{definition}[Layer-head state]
Fix integers $\mathrm{LAYERS},\mathrm{HEADS},\mathrm{LAGS}$.
At time $t$, define the state key
\[
K_t \in (\mathbb{Z}_B)^{\mathrm{LAYERS}\cdot\mathrm{HEADS}\cdot\mathrm{LAGS}}
\]
as the concatenation of all lag bins for all heads and layers.
\end{definition}

\begin{assumption}[State determinism]\label{ass:state_det}
Given fixed kernel parameters and fixed token stream, the state sequence $(K_t)$ is deterministic.
\end{assumption}

\subsection{Training as set-compilation (no weights, no counts)}
We \emph{do not} estimate probabilities. We compile an exact transition relation as sets.

\begin{definition}[Next-token relation]
For each observed transition $K_t \to y_{t+1}$ (next byte),
store set membership:
\[
\mathrm{NextSet}[K_t] \;\supseteq\; \{y_{t+1}\}.
\]
\end{definition}

\begin{proposition}[Training is MatMul-free]\label{prop:train_nomul}
Training requires no dense matrix multiplication.
\end{proposition}
\begin{proof}
Each step computes a fixed number of integer-key updates and sets a bit in a 256-bit set.
No operation of the form $W x$ with dense $W$ is required.
\end{proof}

\subsection{Inference by sparse associative recall}
To avoid fragile exact-state lookup, we retrieve a \emph{best matching} memorized state by overlap in discrete key space.

\begin{definition}[Overlap score]
For query key $K$ and stored key $K^{(j)}$, define
\[
\mathrm{Overlap}(K,K^{(j)}) \defeq \#\{p : K[p] = K^{(j)}[p]\},
\]
i.e.\ the number of matching components.
\end{definition}

\begin{definition}[Deterministic best match]
Choose
\[
j^\star \defeq \arg\max_j \bigl(\mathrm{Overlap}(K,K^{(j)}),\; \prec_{\mathrm{state}}\bigr),
\]
with fixed tie-break order $\prec_{\mathrm{state}}$ (e.g.\ smallest id).
\end{definition}

\begin{definition}[Deterministic token choice]
Let $A \defeq \mathrm{NextSet}[K^{(j^\star)}]$.
If $A=\varnothing$, the system halts. Otherwise select a token deterministically from $A$
by a fixed function of $K$ (e.g.\ select the $k$-th set bit where $k = \sum_p K[p] \bmod \abs{A}$).
\end{definition}

\begin{theorem}[Inference is MatMul-free]\label{thm:infer_nomul}
Inference requires no dense matrix multiplication.
\end{theorem}
\begin{proof}
Computing overlaps between discrete keys can be implemented via inverted indices:
for each component position $p$ and bin value $K[p]$, consult a posting list of states that share that component.
Scoring increments bounded integer counters; selection over a 256-bit set uses bitwise operations.
No dense dot products or dense matrix-vector products are required.
\end{proof}

\begin{theorem}[End-to-end determinism]\label{thm:end2end}
Under Assumptions~\ref{ass:kernel} and~\ref{ass:state_det}, and fixed tie-break rules,
training yields a deterministic model; inference yields deterministic outputs for a given prompt.
\end{theorem}
\begin{proof}
All operations are deterministic integer computations with fixed parameters and explicit tie-breaking.
\end{proof}

\subsection{Complexity (informal bounds)}
Let $M$ be the number of stored states and $P=\mathrm{LAYERS}\cdot\mathrm{HEADS}\cdot\mathrm{LAGS}$.

\begin{proposition}[Per-token inference cost]\label{prop:cost}
With an inverted index over $(p,\mathrm{bin})$ pairs, best-match retrieval costs
$O\!\left(\sum_{p=1}^{P} \abs{\mathrm{Post}(p,K[p])}\right)$ counter increments,
followed by $O(1)$ operations on a 256-bit set (constant 32-byte scans).
\end{proposition}

\section{Deterministic Safe Division (Auxiliary Result)}
Some deterministic pipelines require normalization ratios. If a denominator can be zero,
a deterministic shift-unshift procedure can be used:

\begin{definition}[Shift-unshift division]\label{def:shiftunshift}
For real numbers $a,b$ and $\delta>0$, define
\[
\mathrm{Div}_\delta(a,b) \defeq \frac{a+\delta}{b+\delta} - \delta.
\]
\end{definition}

\begin{proposition}[Ratio preservation]\label{prop:ratio_preserve}
If $b\neq 0$, then $\mathrm{Div}_\delta(a,b)=\frac{a}{b}$.
\end{proposition}
\begin{proof}
\[
\frac{a+\delta}{b+\delta}-\delta
= \frac{a+\delta - \delta(b+\delta)}{b+\delta}
= \frac{a+\delta -\delta b -\delta^2}{b+\delta}
= \frac{a}{b}.
\]
\end{proof}

\begin{remark}
When $b=0$, $\mathrm{Div}_\delta(a,0)=\frac{a+\delta}{\delta}-\delta$ is defined and deterministic for any fixed $\delta>0$.
\end{remark}

\section{Conclusion}
HDR provides a deterministic, proportional residual-vector framework with exact reconstruction and uniqueness at the representation level.
By introducing a fixed integer key extractor $P$, we obtain sparse discrete resonance keys enabling HRM retrieval and a MatMul-free
transformer-style sequence core. The resulting training and inference pipelines operate via bounded integer operations and sparse associative recall
rather than dense matrix multiplication.
